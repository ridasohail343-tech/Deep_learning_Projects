# Sentiment Analysis Using RNN

A sentiment analysis project using Natural Language Processing (NLP) and a Recurrent Neural Network (RNN) built with TensorFlow and Keras.

## Features

* Text preprocessing
* Keras Tokenizer
* Sequence padding
* Word Embedding
* RNN-based sentiment classification
* Positive and negative sentiment prediction

## Technologies

* Python
* TensorFlow
* Keras
* NumPy
* Pandas
* NLP

## Model

The model uses an Embedding layer followed by an RNN layer and a Dense output layer to classify text sentiment.

## Result

The model predicts whether the given text has a **positive** or **negative** sentiment.
